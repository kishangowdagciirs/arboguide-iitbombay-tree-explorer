
# 🌳 ArboGuide – IIT Bombay Campus Tree Explorer

**Walk closer to unlock the tree's story.**

ArboGuide is an interactive, GPS-enabled campus tree exploration and identification platform developed for the IIT Bombay campus.

The platform connects a digital tree inventory with geographic locations and photographs, helping campus visitors explore and identify trees.

## 🌱 Project Overview

ArboGuide brings the campus tree inventory into an interactive web-based GIS environment.

The current inventory contains approximately **29,064 tree records across five campus areas**.

## ✨ Key Features

- **Interactive Tree Map:** Explore campus trees through an interactive map.
- **GPS-Based Tree Identification:** Locate nearby trees using the device's GPS.
- **Tree Directory:** Search trees using physical Tree Tag ID, common name, scientific name or family.
- **Tree Photographs:** View photographs associated with individual tree records.
- **Area-Based Filtering:** Browse trees across different campus areas.
- **Community Reporting:** Report incorrect tree names, locations and other inventory issues.
- **Evidence Submission:** Submit supporting photographs with reports.

## 🛰️ Technology Stack

- HTML, CSS and JavaScript
- Leaflet.js for interactive mapping
- OpenStreetMap for map data
- Cloudflare R2 for tree photograph hosting
- Google Apps Script for report submission
- Google Sheets and Google Drive for report management
- Netlify for web hosting
- GitHub for source-code management

## 📍 Reporting and Data Quality

Visitors can report incorrect tree identification or location information through the reporting interface.

Submitted reports are maintained separately for administrative review. The master tree inventory remains read-only for public visitors.
